# vgandolfi-dev-ui

Personal portfolio site built with React Router v7, Vite, Tailwind CSS 4, and DaisyUI 5.

## Getting Started

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build
```

## Docker Deployment

```bash
# Build and start the container
docker compose up -d
```

The app will be served on port 80.
